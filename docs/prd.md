# dhs-fanout-test PRD

## Purpose

Test fixture for validating the dhs (dev-harness-layer) install and fan-out across Claude Code, Cursor and OpenCode.

## Users

Developers of dhs who use this repo to test the harness.

## Scope

- Verify generated live agents, work skills and rule packs per host.
- Verify `/dhs-setup` config generation and regeneration.

## Non-goals

- No product features.
- No application code.
